# AnalizadorDeComplejidades

Pequeño proyecto para parsear y analizar complejidades de algoritmos.

Cómo ejecutar:
1. Instalar dependencias:
   python -m pip install -r requirements.txt
2. Ejecutar tests:
   python -m pytest -q

Descripción:
- Código fuente en `src/`
- Gramática en `src/parser/grammar.lark`
- Tests en `tests/`
